Release en desarrollo

v1.1.0 · Night Shift

Night Shift es el primer gran upgrade funcional posterior a Foundation. La pre-release actual es v1.1.0-alpha.1.

En desarrollo v1.1.0-alpha.1
Implementado

Ya disponible

  • Sistema de temas y apariencia de Night Shift.
  • Tema oscuro, persistencia de preferencias y adaptación visual.
  • Sistema de votos Útil / No útil.
  • Backend, frontend, estilos y migración SQL del sistema de votos.
  • Fuente SemVer y codename configurados en package.json.
  • Correcciones responsive para móvil dentro de Night Shift.
En progreso

Trabajo actual

  • Sistema de favoritos por usuario.
  • Backend de favoritos iniciado.
  • Migración SQL de favoritos iniciada.
  • Falta completar integración con interfaz y sección Mis favoritos.
Pendiente

Para cerrar Night Shift

  • Mostrar versión y codename dentro de la interfaz de LabNotes.
  • Completar favoritos de extremo a extremo.
  • Ordenamiento por recientes, útiles y comentadas.
  • Estado Abierto / Resuelto y sus filtros.
  • Pruebas de regresión y validación final del release.
  • Avanzar de alpha hacia beta / rc antes de publicar v1.1.0 estable.

Una función se considera completada únicamente cuando está integrada, probada y versionada.

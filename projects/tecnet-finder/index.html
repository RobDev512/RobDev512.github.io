Proyecto

Un lenguaje para planificar redes

TecNet Finder procesa instrucciones relacionadas con direcciones IPv4, máscaras de red y requerimientos de hosts para realizar cálculos VLSM. El proyecto integra análisis de compiladores con una aplicación gráfica de apoyo. 

IP 192.168.1.0 MASK /24 HOSTS 50,30,10 NAME Oficina

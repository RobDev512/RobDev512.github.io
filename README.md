# RobDev512.github.io

Portal central de proyectos personales de RobDev512.

El objetivo de este repositorio es presentar y organizar proyectos de distintas áreas de desarrollo desde un único sitio público.

Sitio:

https://robdev512.github.io/

## Propósito

El hub no está limitado a proyectos públicos ni a proyectos almacenados en GitHub.

Puede representar:

- proyectos públicos;
- proyectos con código privado;
- aplicaciones desplegadas;
- proyectos locales;
- proyectos en desarrollo;
- experimentos;
- proyectos terminados;
- proyectos archivados.

La clasificación principal se realiza por el tipo de proyecto o área de desarrollo.

Los lenguajes, frameworks, bases de datos y plataformas se utilizan como tecnologías o etiquetas secundarias.

## Categorías principales

- Desarrollo Web
- Desarrollo de Aplicaciones de Escritorio
- Desarrollo de Aplicaciones Móviles
- Desarrollo de Videojuegos
- Automatización y Scripts
- Backend y Servicios
- Datos y Bases de Datos
- Sistemas y Experimentación
- Otros
